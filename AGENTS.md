# Instructions for AI agents

## No AI attribution

Never add AI attribution to anything in this repository or anything published from it:

- No `Co-Authored-By:` trailers naming an AI model or assistant in commit messages.
- No "Generated with ..." or similar footers in pull requests, issues or release notes.
- No mention of AI tools in website pages, blog posts, docs or changelogs.

Commits are authored by the repository owner only.
